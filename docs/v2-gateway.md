# P2.1.2 gateway protocol v1
EITEK master UART 115200 8N1, ASCII lines. gw hello NONCE32 (lowercase hex) returns GW HELLO JSON version, nonce, boot_id (random 16 hex per boot), last_seq, uptime_ms. Kiosk may estimate UTC from round-trip observations, not actual sample/exposure timestamps. gw BOOT16 SEQ UUID32 COMMAND accepts exactly next positive uint32 sequence for current boot; consumes even rejected supported/unsupported command. Older, duplicate, skipped, wrong boot rejected without motion; no replay of cached ACK; never retry unknown outcome. GW ACK JSON version, boot_id, request_id, seq, accepted, reason, uptime_ms, batch_id (empty if none). accepted means handler accepted state transition or configuration; not physical completion, fluid volume or image validation. Existing BATCH/CLEAN status and evidence events still authoritative for progress. Allowlisted batch/clean commands and assay profiles only. No raw pulses, ARM, capture, individual start, or arbitrary shell. STOP remains raw emergency best effort and is not an ACK of physical stop. Read-only status probes remain raw. Existing UART console not authenticated, no concurrent operator terminal; physical access required. Sequence RAM only, boot binding prevents old boot frames; Kiosk journals commands durably. Reboot/timeout require operator inspection, no automatic resume. Modbus V4 unchanged. Hardware acceptance in P3.
