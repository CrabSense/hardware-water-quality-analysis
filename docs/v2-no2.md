# P1.2 supervised NO2 Sera commissioning

Manufacturer instructions (https://www.youtube.com/watch?v=u5dB0hlZwa8, sera GmbH, 2026-02-03; https://www.sera.de/en/service/faq/faq-detail/using-the-sera-nitrite-test/): rinse, 5 mL sample, 5 drops reagent 1 then mix, 5 drops reagent 2 then mix, compare after 5 minutes; clean vial before/after. Confirm actual kit leaflet/revision before use. No concentration is calculated in this firmware.

## Required prerequisites
Disabled by default (`WQ_ENABLE_NO2_SUPERVISED=0`). First test only clean water and dummy loads. Both boards require V4. Before enabling locally: validate safe electrical wiring, RS485, output timing, actual pump volumes, hydraulic path isolated to NO2 vial (including vial 4), chemical-compatible tubing, waste collection, no backflow, correct reagent lot, actual equivalent uL for five drops of each reagent, both CH1/2 verified calibration in that range, independent stable illumination and real camera/receiver. No fill selector/mixer/level feedback in current wiring. A shared manifold may make selective filling impossible; do not enable if not isolated. Source/sample/drain/total timings are user-measured, no defaults or assumed rates. No OUT8 relay while USB active: external stable light must be independently controlled; verify safe optical geometry/colour calibration. No real reagent until commissioning gates passed.

Master serial (values are measured integers; not a ready-made prescription):
    no2 profile SOURCE_MS SAMPLE_MS R1_UL R2_UL DRAIN_MS TOTAL_MS
    no2 start
    no2 status

Profile stored in RAM only; no automatic restart after reset. Start means operator confirms vial cleaned/rinsed, hydraulic path isolated, bottles prepared and illumination/receiver ready. Preflight validates exact requested reagent volumes on slave with no output motion. Source OUT1 then sample OUT2, one at a time; operator verifies actual 5 mL and sends `no2 confirm`. CH1 dose then operator mixes and confirms; CH2 dose then operator mixes and confirms. Five-minute timer starts at second mixing confirmation; operator must mix and confirm promptly. No auto stirring or automatic pre/post rinse. Each waiting confirmation has a 120-second abort limit, not a chemical tolerance. Validate actual reaction timing and capture delay versus leaflet; USB enumeration can delay exposure beyond 300 s, not yet suitable for unattended quantitative analysis.

At reaction deadline master disarmed requests camera. Slave sends JPEG on its USB-UART. A separate receiver must listen BEFORE master capture. Validate CRC, dimensions, decode, identity, time and image quality; then enter `no2 image ID` at master (ID from NO2 IMAGE log). This is an explicit operator attestation, not automated receiver proof. 60 s image-stage limit; camera busy/fault blocks drains until confirmed idle. If no valid image do not confirm. Successful confirmation runs OUT3 then OUT7 measured pulses; waste must be captured, never returned to farm water. After completion manually clean vial per kit. No NO3/NH3 or reserve valve actuation.

STOP, timeout, lost communication during actuation, invalid recipe or interrupted receipt: no auto retry, all outputs disarmed best effort, no automatic drain on fault. Inspect and recover manually; after remote state 0 and safe recovery, `no2 reset`, then re-enter profile. Image-phase temporary link loss allowed only with loads off; link and camera idle required for confirmation. Local slave UART commands are trusted bench only; do not issue other commands while recipe active. Host tests verify state transitions and timing arithmetic only; no hardware, chemistry, lighting or hydraulic validation. Actual electrical pulse completion is not measured liquid volume. No unattended operation.
