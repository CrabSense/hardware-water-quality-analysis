# P1.6 — supervised drain and rinse

Default WQ_ENABLE_CLEAN_SUPERVISED=0, output and RS485 flags remain disabled. Not an unattended CIP system. Existing hydraulics have no verified selector, level, flow, leak or residue sensing. Validate plumbing, waste isolation and safe drain path before enabling; no simultaneous valves/pumps. If plumbing requires concurrent drain valves, this sequence is incompatible until redesigned. Use separate clean rinse water and ensure no residual chemicals flow into culture tank or reagent tubing. Follow actual kit cleaning/SDS instructions; rinse timing alone does not prove cleanliness. No detergent or reagent added by firmware.

Dirty journal on EITEK NVS (wq-clean-v1/dirty) encodes 3-bit mask, schema/magic and complement. First boot, missing/corrupt data => all dirty; writes and reads back before operation. New single or batch assay requires all three bits clean and marks selected bits dirty before motion. Manual ARM conservatively marks all three dirty. STOP, recipe reset, batch reset and power loss never clear dirty. Cleaning start marks selected bits before motion. Only after every selected vial completes all configured cycles and operator verifies each, persist clearing selected bits; interrupted cleaning retains all selected dirty, even if a subset finished. Storage error locks starts until investigation/reboot; do not erase NVS as a shortcut. Hardware/firmware integrity and actual residue removal not guaranteed by a journal. No auto restart, no actual UTC.

Commands (master UART; values must be measured, no defaults):
- clean status: step, dirty mask, selected/verified mask, vial, cycle, storage health, ready_for_assay.
- clean profile ID SOURCE_MS FILL_MS SETTLE_MS DRAIN_MS TOTAL_MS CYCLES. ID 1 NO2, 2 NO3, 3 NH3. Pulses 1–10000 ms, settle 0–60000 ms, cycles 1–5. Each selected vial requires own profile. RAM only.
- clean start MASK: 1/2/4 or combination 1..7. Allowed with no active assay, including after complete/fault, fresh disarmed link. Operator must inspect and recover safely after prior fault. Select all dirty vials before next assay.
- clean route ID: only after prompt, confirm isolated feed (including reserve vial 4), clean rinse supply, adequate volume/headroom, safe waste collection and any manual prior recovery.
- clean verify ID: after initial drain and all rinse cycles, confirm actual rinse/empty vial and clean shared path. Visual inspection is not quantitative chemical residue validation. If not acceptable, STOP, reset and repeat after correction.
- stop / clean stop: abort; no auto retry/drain.
- clean reset: clears cleaning RAM/profile only, never clears dirty journal. After cleaning completion, reset owning assay/batch separately to release existing ownership. Configure next profiles.

For each selected vial: OUT(3/4/5) initial drain -> OUT7 initial total drain -> repeat OUT1 source, OUT2 fill, nonblocking settle, individual drain, OUT7 total drain -> operator verification. No OUT6, OUT8 or MOSFET dosing. One timed actuator at a time. 120 s operator wait and 30 min overall software bounds, not chemical tolerances. On link loss, timeout, storage error or interrupted pulse, all loads disarm best effort and dirty retained. Manual bench arming is intentionally permitted when journal healthy even if dirty, to allow calibration with dummy loads; actual chemical analysis is gated. Independent slave CLI not allowed during cleaning. Modbus V4 unchanged.

P3 consolidated acceptance: test NVS power cuts before/during/after pulse and commit, missing/corrupt state, OFF deadlines, valves fail positions, leaks, overfill, drain routing, backflow, chemical carryover/blank controls and appropriate cleaning protocol for actual reagents. Host tests exercise state/encoding, not physical cleaning or NVS power-cut behavior.
